## 🧩 About

**Borderlands 4 ESP Menu** is a curated list of Borderlands 4 open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, checkpoint switcher
- **Quality-of-Life Helpers** — loot catalog, skin manager, overlay notes

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Checkpoint Switcher — practice from any checkpoint
- Show Hitboxes — visualize enemy and loot hitboxes
- Replay Notes — record and review combat runs
- Playback Speed — adjust game speed for study (0.1x to 5x)

### Wallhack
- Loot Catalog — browse weapons, shields, grenades, class mods
- Custom Skin Notes — organize character cosmetics
- Highlight Loot — improved loot visibility

### Aimbot
- Practice Mode Notes — segment study on any map
- Gravity Flip Control — manually switch gravity mid-jump
- Jump Buffer Notes — chain complex maneuvers in the editor
